## 🛠 How to Use in Your Project

1. Copy [`NCL-FW-LICENSE.md`](NCL-FW-LICENSE.md) into your project's root folder as `LICENSE` or `LICENSE.md`.
2. Update the copyright line with your name / organization and year:
   ```text
   Copyright (c) [YEAR] [YOUR NAME OR ORGANIZATION]. All rights reserved.
   ```
3. (Optional) Update Section 4 contact details for commercial licensing inquiries.
